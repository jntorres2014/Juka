Diagramas — Juka (tesis)

Renderizados con Mermaid.js. Cada diagrama tiene su archivo .mmd editable en esta misma carpeta. Usá los botones para descargarlos como PNG (alta resolución) o SVG (vectorial, ideal para imprimir).

Figura 1 — Arquitectura general por capas

Figura 1. Vista por capas de la arquitectura de Juka. La aplicación sigue un patrón MVVM con separación entre Presentación (Jetpack Compose), ViewModels, Dominio (use cases y modelos) y Datos (repositorios, fuentes locales y remotas).

Figura 2 — Casos de uso del pescador

Figura 2. Diagrama UML de casos de uso. El pescador interactúa con el sistema mediante nueve casos principales; las relaciones «include» y «extend» muestran las dependencias entre tareas. Los servicios externos (Firebase, Gemini, ML Kit) participan como actores secundarios.
